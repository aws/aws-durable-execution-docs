# Guides

Task-focused guides for building and deploying durable functions, beyond the operation reference
and the getting started tutorials.

[JavaScript runtimes](javascript-runtimes.md) covers deploying a durable function on the managed
Node.js runtime and on container images carrying Bun, Deno, or LLRT: the execution role and the two
timeouts every option needs, CDK for both zip and image packaging, the bundling rules each runtime
imposes, and measured cold start, memory, and replay figures to choose between them.
