# OpenTelemetry plugin for Java is now stable

_August 2026_

Version 2.2.0 of the AWS Lambda Durable Execution SDK for Java promotes the plugin
platform and OpenTelemetry APIs from preview to stable. If you used the experimental
OpenTelemetry plugin from 2.1.0, follow the migration notes in the
[v2.2.0 release notes](https://github.com/aws/aws-durable-execution-sdk-java/releases/tag/v2.2.0).

## What changed

- **Stable plugin platform** The plugin and OpenTelemetry APIs are now stable. Plugins can
    be loaded dynamically through the `DURABLE_EXECUTION_PLUGINS` environment variable,
    including `otel-invocation` and `otel-execution` providers for Lambda layers.
- **OpenTelemetry plugins** The preview `OtelPlugin` is replaced by `InvocationOtelPlugin`,
    with a new workflow-rooted `ExecutionOtelPlugin`. Configuration is consolidated under
    `OtelPluginConfig`, and no-argument constructors support ADOT Java agent integration.
- **Expanded lifecycle hooks** Hooks now cover operation changes, execution input and
    output, operation results and state, replay details, and `UserFunctionOutcome`.

## Migrating from the preview plugin

These steps apply only if you used the experimental OpenTelemetry plugin from 2.1.0:

- Replace `OtelPlugin` with `InvocationOtelPlugin`, or use `ExecutionOtelPlugin` for
    workflow-rooted traces.
- Move custom constructor options to `OtelPluginConfig`.
- Rename the MDC field `traceSampled` to `otelTraceSampled`.

No migration is required if you did not use the preview plugin.
