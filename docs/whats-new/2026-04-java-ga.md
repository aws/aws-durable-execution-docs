# Durable Execution SDK for Java is generally available

_April 2026_

The AWS Lambda Durable Execution SDK for Java is now generally available, adding Java to
the set of supported languages for building durable functions.

## What this means

- Write durable workflows in Java with steps, waits, wait-for-condition, callbacks,
    invoke, and the `map` / `parallel` concurrency operations.
- Configure workflow behavior through `DurableConfig`, including the serializer and
    execution options.
- Test workflows locally with the Java testing library before deploying.
