# Durable Execution SDK for Rust is in preview

_August 2026_

The AWS Lambda Durable Execution SDK for Rust is now available as an experimental
preview. It is not intended for production use while in preview.

## What this means

- Build durable functions in Rust and try the SDK before it reaches general
    availability.
- The API surface may change based on feedback before GA.

## Give feedback

Feedback shapes the SDK before it is finalized. Share suggestions, ideas, and bug
reports through
[GitHub issues](https://github.com/aws/aws-durable-execution-sdk-rust/issues) and
[discussions](https://github.com/aws/aws-durable-execution-sdk-rust/discussions).
