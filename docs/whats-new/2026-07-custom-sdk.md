# Bring your own Durable Execution SDK

_July 2026_

AWS Lambda durable functions now support a custom Durable Execution SDK. You are no
longer limited to the AWS-provided SDKs: you can build durable workflows against the
checkpoint protocol directly.

## What this means

- Teams with languages or frameworks not yet covered by an official SDK can implement
    the durable execution protocol themselves.
- The AWS-provided SDKs for TypeScript, Python, Java, and .NET remain the recommended
    path for most workloads.
