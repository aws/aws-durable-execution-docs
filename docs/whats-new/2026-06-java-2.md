# Durable Execution SDK for Java 2.x

_June 2026_

Version 2.0 of the AWS Lambda Durable Execution SDK for Java is a breaking major release
that brings Java in line with the other SDKs. Review the
[Java migration guide](https://github.com/aws/aws-durable-execution-sdk-java/blob/main/docs/migration-1.x-to-2.x.md)
before upgrading from 1.x.

## What changed

- **Step semantics** `StepConfig.semantics(...)` is removed. Use `semanticsPerRetry(...)`,
    and add `retryStrategy(RetryStrategies.Presets.NO_RETRY)` to preserve the old
    at-most-once behavior.
- **Log field names** The logger MDC fields were renamed to align across SDKs:
    `durableExecutionArn` becomes `executionArn`, `contextId` becomes `operationId`, and
    `contextName` becomes `operationName`.
- **Replay state** `isReplaying()` now belongs on `DurableContext`, and `StepContext` no
    longer exposes replay state.
- **First-run round trip** Serialized operation results and exceptions are deserialized
    before checkpointing by default, so a custom `SerDes` must support the SDK-managed
    round trip. Disable it with
    `DurableConfig.builder().withDeserializeAfterSerialization(false)`.
- **Invalid context usage** now throws `IllegalStateException` instead of
    `IllegalDurableOperationException`.
